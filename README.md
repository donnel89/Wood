# pallet-woodworking

סקיל ל-Claude Code: מדריך אישי לנגרות ממשטחי עץ (פלטות) למתחיל.

## תוכן

| קובץ | תוכן |
|---|---|
| `SKILL.md` | פרופיל המשתמש, מבנה התשובה לכל פרויקט, כללי בטיחות |
| `references/pallet-safety.md` | זיהוי משטח בטוח (HT/KD/DB מול MB), סימני אזהרה, שיטות פירוק, מידות נפוצות |
| `references/project-ideas.md` | רעיונות לפרויקטים ב-3 רמות קושי |
| `references/finishing.md` | שיוף, שריפה בברנר (שו סוגי באן), ריסוס צבע, חותמת לוגו |

## התקנה

```bash
git clone https://github.com/donnel89/Wood.git \
  ~/.claude/skills/pallet-woodworking
```

לשימוש בפרויקט מסוים בלבד, שכפל במקום זאת אל `.claude/skills/pallet-woodworking` בתוך הפרויקט.

## שימוש

הסקיל נטען אוטומטית כשעולה נושא של משטחי עץ, נגרות, פירוק משטח, שיוף, צביעה, שריפה בברנר או רעיון לפרויקט — גם בעברית וגם באנגלית.
